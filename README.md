# Horria Lab
برنامج تسجيل توريدات المصنع (قبول / رفض) — متصل بـ Google Sheets
**Developed By Eng. Ahmed Adel**

---

## 1) تثبيت البرنامج على جهازك

1. ثبّت بايثون (نسخة 3.9 أو أحدث) من [python.org](https://www.python.org/downloads/) — تأكد من تفعيل خيار **Add to PATH** أثناء التثبيت.
2. فك ضغط مجلد `HorriaLab` في أي مكان على جهازك (مثلاً سطح المكتب).
3. افتح **Command Prompt** / **Terminal** داخل المجلد ونفّذ:

```
pip install -r requirements.txt
```

## 2) إعداد خط عربي (لازم للتقارير PDF)

حمّل أي خط عربي مجاني (Regular + Bold) مثل **Amiri** أو **Noto Naskh Arabic** أو **Cairo**،
وضع ملفات `.ttf` داخل مجلد `fonts` بجانب `main.py`. البرنامج يكتشفها تلقائيًا.

## 3) ربط البرنامج بجوجل شيت (Service Account)

1. ادخل على [Google Cloud Console](https://console.cloud.google.com/).
2. أنشئ مشروع جديد (أو استخدم مشروع موجود).
3. من قائمة APIs فعّل: **Google Sheets API** و **Google Drive API**.
4. من "Credentials" أنشئ **Service Account** جديد.
5. داخل الـ Service Account أنشئ **Key** بصيغة JSON وحمّله — هذا هو ملف الاعتماد المطلوب في البرنامج.
6. افتح الشيت الذي تريد الربط به في Google Sheets، واعمل **Share** بصلاحية **Editor** على البريد الإلكتروني الخاص بالـ Service Account (تجده داخل ملف الـ JSON، ينتهي بـ `@....iam.gserviceaccount.com`).
7. انسخ **Sheet ID** من رابط الشيت:
   `https://docs.google.com/spreadsheets/d/SHEET_ID_HERE/edit`

## 4) تشغيل البرنامج

```
python main.py
```

من داخل البرنامج اضغط **⚙ إعدادات الاتصال بجوجل شيت** وأدخل:
- مسار ملف JSON
- Sheet ID
- اسم الشيت الفرعي (افتراضيًا: `بيانات`) — البرنامج هيعمله تلقائيًا لو مش موجود، وهيحط العناوين:
  `التاريخ | نوع الوارد | اسم المورد | اسم المنتج | الحالة | ملاحظات`

## 5) طريقة الاستخدام

- **تسجيل توريد جديد**: اختر نوع الوارد (خامات رئيسية / خامات تعبئة وتغليف / CF)، ثم اكتب أول حرفين من اسم المورد ليظهر لك اقتراحات مفلترة، وكذلك المنتج، ثم حدد الحالة (مقبول/مرفوض) واكتب ملاحظات لو محتاج، واضغط **حفظ**.
- **سجلات اليوم**: تظهر تلقائيًا في الجدول أسفل الفورم، مع زر **تحديث السجلات**.
- **تقرير اليوم PDF**: يطبع كل توريدات اليوم المحدد في حقل التاريخ بتقرير PDF احترافي.
- **تقرير شهري (رفض) PDF**: يطبع كل حالات الرفض في شهر/سنة معينة، مع ملخص عدد مرات الرفض لكل مورد.
- **بحث عن مورد**: اكتب اسم المورد (أو جزء منه) ويطلع لك تقرير PDF بكل توريداته وعدد مرات القبول والرفض.

كل تقارير الـ PDF مطبوع فيها اسم البرنامج **Horria Lab** واسم المطور **Eng. Ahmed Adel** في الهيدر والفوتر.

## 6) استيراد بياناتك القديمة (اختياري)

عندك ملف إكسيل قديم فيه بيانات شهر يوليو. لو عايز تستوردها في نفس الشيت الجديد،
افتح شيت جوجل الذي أنشأته، وارفق فيه ورقة (Sheet) اسمها `بيانات` بنفس ترتيب الأعمدة:

```
التاريخ | نوع الوارد | اسم المورد | اسم المنتج | الحالة | ملاحظات
```

وانسخ بياناتك القديمة (التاريخ، نوع الوارد، اسم المورد، اسم المنتج، الحالة) يدويًا أو عن طريق لصق الأعمدة بنفس الترتيب،
واترك عمود "ملاحظات" فاضي لو مفيش ملاحظات قديمة.

## ملاحظات تقنية

- البرنامج مبني بـ **Tkinter** (واجهة رسومية) + **gspread** (ربط جوجل شيت) + **reportlab** (تقارير PDF).
- لو ظهرت رسالة خطأ بخصوص الصلاحيات، تأكد إنك عملت Share للشيت مع بريد الـ Service Account بصلاحية Editor.
- ملف `config.json` بيتحفظ تلقائيًا بجانب البرنامج بعد أول اتصال ناجح، وبيفتح تلقائيًا في المرات الجاية.
